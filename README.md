# Numerix 🧮🔢

A clean, cross-platform calculator application built with **Flutter**. Numerix delivers fast, accurate arithmetic calculations with a responsive interface designed for mobile, web, and desktop devices.

## ✨ Features

* **Basic Arithmetic Operations:** Perform addition, subtraction, multiplication, and division effortlessly.
* **Clear & Backspace Controls:** Quickly reset the current expression or delete single digits.
* **Decimal & Percentage Support:** Handle floating-point numbers and quick percentage calculations.
* **Cross-Platform Support:** Runs smoothly on Android, iOS, Web, Windows, macOS, and Linux.

## 🚀 Getting Started

Follow these steps to run Numerix locally on your machine.

### Prerequisites

* [Flutter SDK](https://flutter.dev) installed and configured
* Dart SDK (included with Flutter)
* An IDE such as [VS Code](https://visualstudio.com) or [Android Studio](https://android.com)
* An emulator, simulator, or physical device

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```

2. **Navigate to the project directory:**
   ```bash
   cd numerix
   ```

3. **Install dependencies:**
   ```bash
   flutter pub get
   ```

4. **Run the app:**
   ```bash
   flutter run
   ```
